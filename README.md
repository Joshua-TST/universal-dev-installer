# Universal Dev Installer

A one-click universal installer for setting up a developer environment on Windows, macOS, or Linux.

## Tools Installed

- Python
- Visual Studio Code
- Node.js
- Google Chrome
- Firefox
- Postman
- ngrok
- WSL (Windows only)

## Usage

### Windows

Double-click `run_installer.bat` or run in PowerShell:

```powershell
.\install_windows.ps1
